refactor: split widgets.py

The widgets of widgets.py move, byte-exact, to
shared/widgets/<theme>.py when several parts or library code use
them (style, basic_widgets, push_buttons, message_box, line_edits,
numeric_inputs, combo_boxes, item_views, search_widgets,
lut_items, plot_items, toolbars, imshow_window), to
gui/mixins/widgets.py when only the GUI mixins shared with the
measurements viewer use them, and next to their single user
otherwise (gui/widgets/, measurements_viewer/widgets.py, dialogs
and utilities). The pyqtgraph configuration and colormaps load
with shared/widgets/style.py; load.get_all_buttons_names reads
push_buttons.py. widgets.py is a split shim.
