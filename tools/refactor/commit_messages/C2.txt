refactor: add the compat layer for moved import paths

cellacdc/_compat.py (stdlib only): alias_module for modules moved
whole (sys.modules alias: the old path is the same module),
moved_module for split modules (lazy, uncached __getattr__ and
__dir__ that resolve through the home module), package_compat for
gui, measurements_viewer and myutils, which become packages, and
CompatModule, which forwards patches of moved names to every
module that holds the old module's code (deleting a name that a
pending patch set undoes that patch, as the undo of mock.patch and
of pytest >= 9.2's monkeypatch expects). Every use of an old path
warns with MovedWarning (a DeprecationWarning, message prefix
"Cell-ACDC import path moved:"). cellacdc/_compat_moves.py, the
old -> new tables, is generated by every following move commit;
it is empty here. No module moves yet.
